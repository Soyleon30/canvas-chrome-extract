# Canvas 图表导出 MV2

Canvas 图表导出 MV2 是一个浏览器扩展，用于从当前网页中扫描、预览并导出 canvas 图表。它适合 ECharts、v-chart、Chart.js 以及其他最终渲染到 canvas 的监控图、趋势图、仪表盘图表。

当前版本：1.2.0。插件界面与插件元信息已改为中文，支持自定义导出背景色，并可选配置写入文件名的页面文本路径。

## 适用场景

- 从运维监控、报表系统、可视化大屏中批量导出 canvas 图表
- 导出 ECharts、v-chart、Chart.js 等图表为 PNG
- 为深色主题图表补一个固定背景色，避免透明 PNG 放到文档里看不清
- 复制 canvas 扫描报告默认隐藏，可通过 `Alt` 双击标题打开，用于定位页面中的图表元素和导出失败原因

## 适用浏览器

统信 UOS、银河麒麟 V10 等环境中的旧版 360 浏览器。

- Manifest V2 版本，使用 `chrome.tabs.executeScript` 注入页面脚本。
- 用于最高只支持 Manifest V2、无法识别 `scripting` 权限的旧 Chromium 内核浏览器。

## 安装方式

1. 打开浏览器的扩展管理页面。常见入口包括 `chrome://extensions/`、`se://extensions/`，或浏览器菜单中的“扩展程序”。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `canvas-extractor-extension-mv2` 目录。
5. 打开目标页面，等待图表渲染完成后点击工具栏里的“Canvas 图表导出”图标。

## 使用说明

1. 打开包含 canvas 图表的网页。
2. 点击浏览器工具栏中的插件图标。插件会自动扫描当前标签页及其 frame 中的 canvas。
3. 选择导出背景：
   - “背景色”：把 canvas 合成到指定纯色背景上，默认颜色是 `#0a0d19`。
   - “透明背景”：保留原始 canvas 的透明效果，不额外填充背景。
4. 如需修改背景色，使用颜色选择器或直接输入 `#RRGGBB` 格式的颜色值。修改后插件会重新扫描并刷新预览。
5. 在列表中查看每个 canvas 的预览、真实像素尺寸、页面显示尺寸、frame 编号和 CSS selector。
6. 点击“下载 PNG”导出单个图表，或点击“下载全部”批量导出所有可读取的图表。
7. 如需在文件名前加入页面文本，勾选“写入文件名前缀”，并填写 CSS selector。多个路径用中文分号 `；` 分隔，插件会按顺序取第一个匹配到的文本。
8. “复制报告”默认隐藏；按住 `Alt` 双击弹窗标题“Canvas 图表导出”可显示或隐藏该按钮，用于复制尺寸、导出状态、frame URL、selector、文件名前缀和错误信息。

## 导出文件名

导出的 PNG 会保存到 `canvas-extractor/页面标题/` 目录下。文件名包含序号、图表名称、背景模式或背景色、图片尺寸。

默认文件名前缀路径是 `.newKpi2.col .title span.text-blue`。如果匹配到的文本里包含 IP 地址，插件会优先取 IP；否则使用该元素的完整文本。取消勾选“写入文件名前缀”后，导出文件名不会加入这段页面文本。

## 功能列表

- 扫描当前页面和子 frame 中的所有 `canvas`
- 显示 canvas 预览、真实像素尺寸、页面显示尺寸和 CSS selector
- 支持自定义背景色，默认 `#0a0d19`
- 支持透明背景导出
- 单个下载 PNG
- 一键下载全部可导出的 PNG
- 可选写入页面文本到文件名前缀
- 文件名前缀路径支持多个 CSS selector，并用中文分号 `；` 分隔

## 注意事项

如果 canvas 内使用了没有 CORS 授权的跨域图片，浏览器会阻止 `toDataURL()`，对应项会显示为“受限”。这是浏览器安全策略，不是插件故障。纯 ECharts、v-chart、Chart.js 图表通常可以正常导出。

如果页面图表是延迟渲染的，请等图表完全出现后再点击插件，或点击右上角“重新扫描”。
